# Óscar Barja - Embedded Systems Built to Fly
I design electronics as if they were going to space, because sometimes they are.

## 🧩 About Me
Aerospace engineering student focused on embedded systems, where software and hardware meet under real constraints.
I work close to the hardware, writing firmware, drivers, and system-level code that is expected to run on real boards.




## 🛠️ Skills
My main focus is **embedded software and applied electronics**, working mostly in **C on ESP32-based systems** using **ESP-IDF and FreeRTOS**.  
I spend a lot of time developing **low-level drivers (SPI, I2C)**, designing **clean abstraction layers (HAL / OSAL)**, and making sure hardware and software actually work together.


## 🚀 Solaris (UVigo Aerotech)

Head of Electronics in **Solaris**, a university rocketry project.  
I work on **defining and maintaining the electronics subsystem**, combining coordination with hands-on development.

I actively write **embedded firmware and low-level drivers**, contribute to **system-level code**, and work closely with the hardware during **integration, debugging, and validation**.

I also lead the **Solaris Packet Protocol (SPP)**, a **modular communication system** built around clear abstractions and robustness, designed to support real avionics needs under flight constraints.
